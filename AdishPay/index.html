The Evolution of AdishPay

A project that grew from a simple command-line experiment into a complete web application.

C++ → Web

01 · C++ ATM Simulator

The original concept started as a command-line ATM simulator built while exploring programming fundamentals, user input, account operations, and transaction logic.

02 · AdishPay Web Application

The concept was later expanded into a full-stack web application with authentication, sessions, MySQL database integration, balance management, and transaction workflows.

↓

From understanding transaction logic to building the complete application around it.

Core Features

Practical full-stack concepts implemented inside the AdishPay application.

User Authentication

Registration, login, password verification, session management, and authenticated dashboard access.

Money Transfer

Simulated peer-to-peer transfers with receiver validation, balance updates, transaction PIN verification, and transaction feedback.

Transaction Ledger

Users can view recent transactions and their transaction history through the dashboard.

Database Integration

MySQL provides persistent application data while PHP handles database communication and application logic.

Security Practices

Password hashing, session management, prepared SQL statements, and server-side validation are used throughout the project.

Responsive Interface

A custom responsive interface designed to provide a consistent experience across desktop and mobile screens.

Technology Stack

HTML5 CSS3 JavaScript PHP MySQL Font Awesome Responsive Design
Educational Project
AdishPay is a banking and wallet simulation created for learning and demonstrating full-stack web development concepts. It is not a real financial service and does not process real-world payments.
